# UniSchedule Design System

## Design direction
A minimalist student planner with clear spacing, readable cards, and a consistent university blue-and-gold palette.

## Colors
- Primary university blue: `#003E7E`
- Accent gold: `#F2B300`
- Page background: `#F5F7FA`
- Main text: `#202938`
- Secondary text: `#687386`
- Cards: `#FFFFFF`
- Borders: `#E8ECF2`

## Screens
Demo entry, Dashboard, Class Schedule, Assignments, Exams, and Profile.

## Data and limitations
The current implementation uses in-memory demonstration data. It has no server, account authentication, cloud sync, or permanent local persistence.
